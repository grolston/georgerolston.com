# georgerolston.com

Personal landing page for George Rolston, served by GitHub Pages at
<https://www.georgerolston.com> from the `master` branch (see `CNAME`).

It's a single static page: `index.html` holds the markup, styles, icons, and the script that paints the backdrop, with no
build step and no dependencies beyond two Google Fonts. Edit it and push to `master` to deploy.
